# Big Data and Distributed Information Systems

Лабораторні роботи з Big Data та курсу «Розподілені інформаційні системи».

| Папка | Лабораторна |
|---|---|
| [Lab2_HR](Lab2_HR/) | HR-система в PostgreSQL, MongoDB і Neo4j |
| [Lab3_MapReduce](Lab3_MapReduce/) | Аналіз транзакцій через Hadoop MapReduce |
| [Lab3_StorageRetrieval](Lab3_StorageRetrieval/) | Порівняння PostgreSQL і DuckDB на аналітиці продажів |
| [Lab4_HDFS](Lab4_HDFS/) | Блоки HDFS, збої, відновлення та вартість дрібних файлів |
| [Lab4_RPC_MessageBroker](Lab4_RPC_MessageBroker/) | Protocol Buffers, gRPC і RabbitMQ: кодування даних, RPC і черга повідомлень |
| [Lab5_Spark_1](Lab5_Spark_1/) | Spark RDD, ліниві обчислення, кешування та паралелізм |

Опис і команди запуску — у README відповідної лабораторної.
